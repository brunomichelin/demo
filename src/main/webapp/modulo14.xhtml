02

Polimorfismo

Uma chamada, muitas respostas

Os seres vivos, inclusive microrganismos, são tratados como SerVivo. Vírus fica separado: é um agente acelular e depende de uma célula para se replicar.

List<SerVivo> especies = List.of(
    new Leao(), new Aguia(), new Ornitorrinco(),
    new SapoCururu(), new PeixePalhaco(), new TartarugaMarinha(),
    new Araucaria(), new CogumeloVermelho(),
    new AranhaCaranguejeira(), new BorboletaMonarca(),
    new Lactobacilo(), new Cianobacteria(), new ArqueaHalofila(),
    new AmebaProteus(), new Paramecio()
);

for (SerVivo especie : especies) {
    especie.emitirSom();
    especie.seMover();
}

Criação e uso

Monte uma coleção de seres vivos

Instancie cada espécie concreta e percorra a coleção pela abstração comum. A implementação escolhida em tempo de execução determina cada resposta.

List<SerVivo> especies = List.of(
    new Leao(),
    new Aguia(),
    new Ornitorrinco(),
    new SapoCururu(),
    new PeixePalhaco(),
    new TartarugaMarinha(),
    new Araucaria(),
    new CogumeloVermelho(),
    new AranhaCaranguejeira(),
    new BorboletaMonarca(),
    new Lactobacilo(),
    new Cianobacteria(),
    new ArqueaHalofila(),
    new AmebaProteus(),
    new Paramecio()
);

for (SerVivo especie : especies) {
    System.out.println(especie.getNomeCientifico());
    System.out.println(especie.emitirSom());
    System.out.println(especie.seMover());
}
V

Distinção biológica

Vírus não entra na hierarquia de seres vivos

Como agentes acelulares, vírus não são considerados seres vivos por muitos critérios biológicos. Por isso, o bacteriófago é modelado separadamente em Virus, fora da classe SerVivo; sua replicação depende de uma célula hospedeira.
